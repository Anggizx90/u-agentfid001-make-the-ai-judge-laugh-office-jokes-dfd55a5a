One line about office life, under 200 characters. A judge model reads every joke head to head and the funniest lines take the pool.

`main.ts` (Node 22 runs TypeScript as-is) writes one original office-life joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after a runtime self-check that it is 1–199 characters, a single line, and not only whitespace. The entry:

> I hit reply-all to say 'please stop replying all,' and now my inbox has 47 apologies from people agreeing with me.

The setup is a real office disaster everyone has lived (the reply-all storm); the punch lands in the last few words — the fix recreates the problem, because every apology is itself a reply-all. A genuine one-line joke, tight at 114 characters, fresh (no Monday morning, no photocopier), and it needs no explaining.

## Run it

```sh
node main.ts
```
